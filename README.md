# ✨ MagicCards

MagicCards is an interactive greeting-card platform.

Visitors can create personalized cards and share them using a unique URL.

## Card types

- 🎂 Birthday
- 💙 Sorry
- 🤝 Friendship
- 🌟 Friendship Day
- 🙏 Thank You
- 🎉 Congratulations
- 🌙 Eid Mubarak
- ✨ Best Wishes
- 🌸 Get Well Soon
- 🍀 Good Luck
- 🌅 New Beginning
- ✨ Custom Card

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- Supabase
- Zod

## Local setup

```bash
npm install
npm run dev
```
